## 一、背景与目标

### 1.1 业务诉求

周报 v2.3 已实现"按公司拆分"（4 家公司对比），但仍有两个**关键视角缺失**：

1. **整体 vs 市场化双口径对比**：无法看清"集团整体业绩"与"市场化短期博弈"的差异
2. **18 组织 × 整体/市场化双口径分析**：分公司层面无法识别"市场化率高+折价"的风险组织

### 1.2 数据基础

用户提供了两份数据：
- **国内整体销售**（18 组织 × 6 指标 × 4 维度）
- **国内市场化交易**（18 组织 × 6 指标 × 4 维度）

两份数据来自"2026 年第 21 周周数据综合分析报表"，共 **324 个数据点**（18 × 6 × 3 维度）。

### 1.3 设计目标

| 目标 | 衡量 |
|-----|------|
| 增加"市场化率"维度的可视化 | 18 组织市场化率排行 + 象限图 |
| 支持"整体 vs 市场化"快速对比 | 4 模式 + 双 Tab |
| 识别"高市场化+折价"风险组织 | 象限分类 + 业务洞察 |
| 保持向后兼容 | DomesticAnalyzer 接口不变 |

### 2.2 核心计算公式

**1. 市场化率**（衡量市场化交易占比）
```
市场化率 = 市场化电量 / 整体电量 × 100%
```
- 范围: [0, 100]
- 上限截断: > 100% 时返回 100%
- 边界: 整体为 0 → 返回 0

**2. 电价差**（衡量市场化相对整体的溢价/折价）
```
电价差 = 市场化电价 - 整体电价
```
- 正数 = 溢价（市场化更值钱）
- 负数 = 折价（市场化更便宜）
- 单位: 元/度

**3. 象限分类**（业务定位）
```
市场化率 >= 50%  → 高市场化率
市场化率 <  50%  → 低市场化率
电价差 >= 0      → 溢价
电价差 <  0      → 折价

象限矩阵:
- 稀缺溢价 (低+溢价): 水电稀缺
- 竞争溢价 (高+溢价): 罕见
- 稀缺折价 (低+折价): 局部场景
- 竞争折价 (高+折价): 典型新能源
```

## 三、关键数据洞察

### 3.1 集团整体

| 指标 | 数值 |
|------|------|
| 集团整体电量 | 80.28 亿度 |
| 集团市场化电量 | 33.20 亿度 |
| **集团市场化率** | **41.36%** |
| 集团整体电费 | 24.93 亿元 |
| 集团市场化电费 | 9.81 亿元 |
| **市场化收入占比** | **39.35%** |

### 3.2 象限分布

| 象限 | 组织数 | 代表组织 |
|------|-------|----------|
| 稀缺溢价 | 2 | 长江电力、三峡建工 |
| 竞争溢价 | 8 | 大部分分公司 |
| 稀缺折价 | 3 | - |
| 竞争折价 | 5 | 三峡能源、福建分等 |
| 不参与 | 2 | 长江环保、三峡发展 |

### 3.3 关键发现

1. **长江电力：稀缺水电典范**（市场化率 26.30% + 电价差 +0.033）
   - 集团收入贡献 > 60%
   - 市场化率低但溢价 → 稀缺资源议价权
2. **三峡能源：典型竞争折价**（市场化率 85.3% + 电价差 -0.136）
   - 高市场化率 + 显著折价 → 新能源竞争白热化
3. **区域分公司分化**：
   - 高市场化率：云南、四川、广东、重庆（100%）
   - 低市场化率：江苏（72%）、浙江（37%）
4. **不参与市场化的组织**：
   - 长江环保、三峡发展（业务模式决定）
