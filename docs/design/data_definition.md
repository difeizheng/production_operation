- **优先匹配简称**：Excel 中常见简称（如"长电"、"新能源"）

## 3. 指标口径

### 3.1 指标清单

| ID | 名称 | 单位 | 类别 | 聚合方式 |
|----|-----|------|-----|---------|
| metric_001 | 电量 | 万千瓦时 | 数量 | 求和 |
| metric_002 | 电价 | 元/千瓦时 | 价格 | 加权平均 |
| metric_003 | 电费 | 万元 | 收入 | 求和 |
| metric_004 | 同比 | % | 趋势 | 计算值 |
| metric_005 | 环比 | % | 趋势 | 计算值 |

### 3.2 指标计算规则

**电费计算**：
```
电费 = 电量 × 电价
```

**同比计算**：
```
同比 (%) = ((本期值 - 去年同期值) / 去年同期值) × 100
```

**环比计算**：
```
环比 (%) = ((本期值 - 上周值) / 上周值) × 100
```

### 3.3 数值精度

- 电量：保留 2 位小数
- 电价：保留 3 位小数
- 电费：保留 2 位小数
- 同比/环比：保留 1 位小数

## 4. 数据源追溯

### 4.1 必须记录字段

每个数据值必须包含 source_trace：
- file：原始文件名
- sheet：Sheet 名称
- row：行号
- col：列号
- cell：单元格坐标（如 A5）
- extracted_at：提取时间

### 4.2 追溯用途

- 数据核对：回溯到原始 Excel 验证
- 错误定位：快速找到问题单元格
- 审计支持：提供数据来源证据

---

## 5. 异常数据处理

### 5.1 异常类型定义

| 类型 | 触发条件 | 处理方式 |
|-----|---------|---------|
| **缺失数据** | 单元格为空或非数值 | 记录 WARN，值设为 null |
| **异常值** | 超出合理范围 | 记录 ERROR，仍记录值 |
| **格式错误** | 无法转换为数值 | 记录 ERROR，值设为 null |
| **组织未找到** | 无法识别组织名 | 记录 WARN，跳过该行 |
| **能源类型未找到** | 无法识别列名 | 记录 WARN，跳过该列 |

### 5.2 合理范围参考

| 指标 | 合理范围 | 异常阈值 |
|-----|---------|---------|
| 电量 | 0 - 1000万万千瓦时 | > 1000万 |
| 电价 | 0 - 1元/千瓦时 | > 1 或 < 0 |
| 电费 | 0 - 100亿元 | > 100亿 |
| 同比 | -100% - 500% | > 500% 或 < -100% |
| 环比 | -50% - 50% | > 50% 或 < -50% |

### 5.3 容错策略

- **部分失败**：某 Sheet/组织失败不影响其他
- **整体继续**：记录所有错误，不中断流程
- **置信度标记**：正常数据 confidence=1，异常数据 confidence<1

## 6. 数据校验规则

### 6.1 Schema 校验

使用 `weekly_data.schema.json` 校验：
- meta 必填字段完整
- organizations 至少包含 1 个组织
- validation_report 状态正确

### 6.2 业务校验

- **电费一致性**：电费 ≈ 电量 × 电价（误差 ±5%）
- **合计一致性**：合计 ≈ 各能源类型之和（误差 ±1%）
- **环比有效性**：环比与上周数据对比计算

---

## 7. 数据优先级

当同一数据有多个来源时，按以下优先级选取：

1. **汇总表 Sheet**（最高优先级）
2. **明细 Sheet**
3. **历史数据推断**
4. **默认值**（最低优先级）
