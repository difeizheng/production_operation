# Streamlit v2/v3 菜单分组（v3.1）- 设计文档

> 配套实施计划：`~/.claude/plans/cozy-mapping-yeti.md`

## 1. 概述

v3.1 在 v3.0 人机协同驾驶舱基础上，把侧边栏从「8 个页面混在一起」重构为「按版本分组」，并加上 v2/v3 数据共享层。

**核心目标**：
- 一眼区分 v2 稳定版 vs v3 生产试用
- 数据在两版之间无缝流转
- 支持 URL 深链（`?version=v2/v3`）
- 渐进式发布：新功能隔离，不影响老用户

---

## 2. 路由架构

### 5 层路由 + 1 个数据桥

```
Layer 0: URL 参数层
    ↓ (?version=v3 | v2)
Layer 1: 版本选择器（app.py 侧边栏 radio + query_params 同步）
    ↓
Layer 2: st.navigation（根据版本返回不同的 Page 列表）
    ↓
Layer 3: 页面层（v2_* 和 v3_* 命名的 .py 文件，加前缀避免冲突）
    ↓
Layer 4: 数据桥（streamlit_app/core/data_bridge.py 统一 session_state）
```

### 决策树

```
用户访问 /?version=v3
    ↓
get_current_version() → 读取 URL 参数
    ↓
st.navigation() 根据版本返回不同 Page 列表
    ↓
render_version_switcher() 渲染侧边栏 radio
    ↓
auto_sync() 自动同步 v2/v3 数据
    ↓
nav.run() 执行当前页面
```

## 3. 数据桥策略

### 3.1 数据结构差异

| 维度 | v2 平台 | v3 驾驶舱 |
|------|---------|----------|
| 数据来源 | `tests/fixtures/weekly_report_merged.json` 或上传 JSON | 上传 Excel（综合分析表） |
| 状态存储 | `st.session_state["bundle"]` | `PipelineState.raw_data` |
| 字段格式 | 嵌套 dict | 嵌套 dict + 4 analyzer results |

### 3.2 桥接方向

```
v3 上传 Excel
    ↓ AnalysisCollector.collect()
state.raw_data: Dict
    ↓ state_mgr.update_field()
st.session_state["bundle"] = {data, results, source: "v3_uploaded"}
    ↓ v2 页面读 bundle
v2 国内分析正常显示
```

### 3.3 指纹去重

```python
# data_bridge.py
def _compute_fingerprint(data) -> str:
    """MD5 前 16 位，避免循环同步。"""
    return hashlib.md5(str(data).encode()).hexdigest()[:16]
```

- 数据未变 → 跳过同步
- 数据变化 → 自动同步
- `force=True` → 忽略指纹强制同步

## 6. 关键设计决策

### Q: 为什么不直接用 Streamlit 原生 pages 目录？
A: 原生 pages 目录按文件名字母序排列，无法分组；且不能在同一入口下动态切换。

### Q: 为什么用 `st.navigation` 而非 `st.sidebar.radio` 手动控制？
A: `st.navigation` + `st.Page` 是 Streamlit 1.27+ 的官方推荐做法，自动处理：
- 侧边栏导航渲染
- URL 同步（深链）
- 页面间状态保留

### Q: 数据共享为什么不直接读 v3 的 session_state？
A: 因为 v2 页面用 `bundle["data"]`、`bundle["results"]`，v3 用 `_analysis_data`、`state_mgr.get().raw_data`。需要桥接层做转换 + 去重（防循环）。

### Q: 默认是 v3 还是 v2？
A: v3（生产试用优先）。可通过 `?version=v2` URL 参数或侧边栏切换器强制 v2。

## 8. 端到端使用流程

### 8.1 启动

```bash
PYTHONPATH=. streamlit run streamlit_app/app.py
# 访问 http://localhost:8501
# 默认进入 v3 主页
```

### 8.2 关键场景

| 场景 | 操作 | 预期 |
|------|------|------|
| 默认 v3 | 打开应用 | 主页显示 "🆕 v3.0 驾驶舱" |
| 切换到 v2 | 侧边栏底部选 v2 | 跳转到 v2 主页 |
| URL 深链 | 访问 `?version=v2` | 直接进入 v2 主页 |
| 数据共享 | v3 上传 Excel → 切到 v2 国内分析 | 直接显示同一数据 |
| v2 稳定 | 访问 `?version=v2` 强制进入 v2 | 即使默认 v3 |

### 8.3 跨版本跳转

```python
# 从 v3 跳到 v2 国内分析
from streamlit_app.core.version_router import get_switch_url
url = get_switch_url("v2", "v2_1")  # → "?version=v2&page=v2_1"
```

## 9. 升级 / 回退路径

### 升级（v2 → v3）
1. 用户访问应用 → 默认 v3
2. 看到 "🆕 v3 驾驶舱" 徽章
3. 点击 "数据驾驶舱" 体验 7 步流程
4. 上传 Excel，跨版本数据自动同步

### 回退（v3 → v2）
- 侧边栏切换器 → 立即切回 v2
- URL `?version=v2` → 强制 v2
- v3 页面有"切到 v2 稳定版"按钮

### 数据清空
```python
from streamlit_app.core.data_bridge import clear_all
clear_all()  # 清空 v2 bundle + v3 state
```
