> 面向电力/能源行业新人的周报阅读手册
> 基于"周例会营销发言材料"实际周报的逐段拆解整理
> 版本：v1.0

## 引言：为什么写这份指南

如果你刚进入电力/能源行业，第一次拿到一份"周报"（周例会营销发言材料），一定会被一堆数字、术语、缩略语淹没：

- "上网电量 89.1 亿千瓦时"——这是什么概念？
- "同比提高 3.2%"——和谁比？
- "度电均价 0.311 元"——是贵还是便宜？
- "度电下降 0.9 分"——几分钱也是钱？
- "金下梯级"——这是个什么电站？
- "欠发套利"——这是金融还是电力？

这份指南将通过一份**真实的"5 月 22 日周报"逐段拆解**，帮你建立"读周报"的**完整心智模型**。

> 📖 **阅读建议**：先通读一遍建立框架，再回头看具体案例。
> 🎯 **目标读者**：刚入行的同事、跨行业转岗、自学人员。

## 第一部分：周报的"三大问题"

**每份电力周报都围绕三个问题展开**：

| 问题 | 对应指标 | 周报里的典型表达 |
|---|---|---|
| **发多少电？** | 量 | "上网电量 X 亿千瓦时，同比提高 X%" |
| **卖什么价？** | 价 | "度电均价 X 元，同比下降 X 分" |
| **赚多少钱？** | 收入 | "发电收入 X 亿元，同比提高 X%" |

📊 **黄金公式**：

```
收入 = 电量 × 度电
```

> 💡 **小白记忆口诀**：
> - **量是面子**（业绩规模）
> - **价是里子**（盈利能力）
> - **收入是结果**（综合表现）

## 第二部分：基础词汇表（必背）

### 1. 单位三件套

| 单位 | 含义 | 类比 |
|---|---|---|
| **度（kWh）** | 1 千瓦时 = 1 度电 | 1000W 用电器开 1 小时 |
| **亿千瓦时** | 1 亿度电 | 1 亿户家庭每户用 1 度 |
| **千瓦** | 装机容量的单位 | 1 度电/小时的发电能力 |

### 2. 价格单位

| 单位 | 含义 | 示例 |
|---|---|---|
| **元/度** | 每度电的价格 | 居民电价约 0.5-0.6 元/度 |
| **分/度** | 1 元的 1% | 1 分 = 0.01 元 |
| **厘** | 1 元的 1‰ | 1 厘 = 0.001 元（金融领域常见） |

> 🧠 **关键认知**：
> "几分钱" 看起来很小，**但乘以亿度就是几亿**——
> 度电下降 0.9 分 × 80 亿度 = **7,200 万元**！

### 3. 时间维度

| 术语 | 英文 | 含义 |
|---|---|---|
| **同比** | YoY (Year over Year) | 与**去年同一周**比较 |
| **环比** | MoM/WoW | 与**上一周**比较 |
| **上周** | Last week | 周报覆盖的 7 天 |

> 🧠 **记忆口诀**：
> - 同比 = "和去年同期比" → 看**长期趋势**
> - 环比 = "和上一周比" → 看**短期波动**

## 第三部分：核心概念详解

### 1. 电源类型（5 大类）

| 类型 | 简称 | 特点 | 度电典型价格 |
|---|---|---|---|
| **水电** | 水 | 看天吃饭、稳定 | 0.25-0.35 元/度 |
| **火电** | 火 | 可控、污染 | 0.35-0.45 元/度 |
| **风电** | 风 | 间歇、补贴退坡中 | 0.30-0.50 元/度 |
| **光伏** | 光 | 间歇、平价化 | 0.35-0.55 元/度 |
| **核电** | 核 | 稳定、占比小 | 0.40-0.45 元/度 |

📌 **重要概念**：
- "**新能源**" = 风电 + 光伏 + 其他可再生能源（不含水电）
- "**大水电**" = 装机大、库容大、跨省调度的大型水电站

### 2. 关键电站（必须认识）

| 电站 | 所在河流 | 装机 | 重要度 |
|---|---|---|---|
| **三峡** | 长江 | 22,400 MW | 世界最大水电 |
| **白鹤滩** | 金沙江 | 16,000 MW | 世界第二大 |
| **乌东德** | 金沙江 | 10,200 MW | "金下梯级"之一 |
| **溪洛渡** | 金沙江 | 13,860 MW | "金下梯级"之一 |
| **向家坝** | 金沙江 | 6,400 MW | "金下梯级"之一 |
| **水布垭** | 清江 | 1,840 MW | "清江梯级"上游 |
| **隔河岩** | 清江 | 1,212 MW | "清江梯级"下游 |
| **江坪河** | 溇水 | 450 MW | 独立支流 |

📊 **金下梯级 = 乌东德 + 白鹤滩 + 溪洛渡 + 向家坝**（金沙江下游四大电站）

### 3. 水库调度的关键水位

| 水位 | 数值 | 含义 |
|---|---|---|
| **死水位** | 145 m | 机组**无法取水**的最低线 |
| **汛限水位** | 145-155 m | 5 月底目标水位（**为汛期腾库容**） |
| **正常蓄水位** | 175 m | 满库（**接近大坝承压极限**） |
| **校核洪水位** | 180.4 m | 万年一遇洪水位 |

> 🧠 **核心洞察**：
> **175 m - 145 m = 30 m 的调度空间**
> 这 30 m 就是水电调度的**全部作业空间**

### 4. 调度的"高级操作"

| 术语 | 含义 | 类比 |
|---|---|---|
| **弃水** | 水库装不下的水被放掉 | 钱太多花不完 |
| **欠发** | 火电少发电（套利手段） | 工资里的"底薪" |
| **套利** | 利用价差获利 | 进货卖货赚差价 |
| **抽水蓄能** | 谷时抽水、峰时发电 | 电力银行的"低买高卖" |

### 5. 价格机制（3 层结构）

| 层级 | 含义 | 典型价格 |
|---|---|---|
| **中长期合同** | 锁定价格（1-3 年） | 火电约 0.39 元/度 |
| **现货市场** | 实时价格 | 0.2-0.5 元/度（波动大） |
| **机制电量** | 保底收入部分 | 约火电标杆价 |

> 🧠 **火电的新玩法**：
> - 中长期 = "**底薪**"
> - 现货 = "**提成**"
> - 容量电费 = "**全勤奖**"
> - 火电少发不是偷懒，是**优化收益**

### 6. 风电的特殊概念

| 术语 | 含义 |
|---|---|
| **海风 / 陆风** | 海上风电 / 陆上风电，海风**电价高 1.5-2 倍** |
| **平价装机** | 无国家补贴的电站（2021 年起新项目） |
| **补贴装机** | 有国家补贴的存量项目（电价高） |

### 7. 关键的"对冲"概念

| 概念 | 含义 |
|---|---|
| **容量电费** | 火电"待命"补贴（度电容量电费 = 容量费/实际电量） |
| **基期效应** | 去年基数低，今年同比看着漂亮 |
| **量价对冲** | 量增 + 价跌 ≈ 收入持平 |
| **一省一策** | 不同省份用不同交易策略 |

## 第四部分：阅读方法论（11 个段位升级）

### 段位 1️⃣：**基础认知**——三个问题

```
看到周报 → 找"量、价、收入" → 看"同比、环比"
```

### 段位 2️⃣：**术语解码**——见到"分"反应"× 亿度"

```
看到"度电 X 分" → 心理反应：× 80 亿度 = X × 8,000 万元
```

### 段位 3️⃣：**量价分解**——拆开看"两个世界"

```
总收入变化 = 量影响 + 价影响
```

### 段位 4️⃣：**因果链**——why-what-how

```
看到"业绩涨" → 追问"为什么" → 来水/装机/政策/市场
```

### 段位 5️⃣：**勾稽验证**——数字之间能对上

```
集团 = 水电 + 火电 + 风电 + 光伏
收入 = 电量 × 度电
```

### 段位 6️⃣：**同比环比双线**——两条故事线

```
同比 = 长期趋势（看"病"）
环比 = 短期情绪（看"药"）
```

### 段位 7️⃣：**多空博弈**——看对冲力量

```
度电 ↑ 拉高均价  ↔  占比 ↓ 拉低均价
容量电费 ↑  ↔  现货价 ↓
```

### 段位 8️⃣：**结构效应**——看占比变化

```
"占比 +2.3 pp" = 结构调整
"度电 +0.1 分" = 单价变化
```

### 段位 9️⃣：**本地化运营**——一省一策

```
湖北 95% 锁价 vs 山东 0% 押现货 vs 陕西 105% 卡线
```

### 段位 🔟：**交易策略**——读懂"仓位"

```
"调减中长期仓位" = 押注现货涨
"高比例中长期" = 押注现货跌
```

### 段位 1️⃣1️⃣：**战略画像**——读懂组织能力

```
数字细节 = 管理颗粒度
跨省对比 = 本地化能力
勾稽完整 = 治理水平
```

## 第五部分：实战案例（5 月 22 日周报逐段拆解）

### 案例 1：总览段

> "上周，集团公司合计上网电量 89.1 亿千瓦时，国内 80.3，国际 8.8"

**怎么读**：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1️⃣ 找"量" | 89.1 亿度/周 | 巨型集团规模 |
| 2️⃣ 找"结构" | 80.3 + 8.8 = 89.1 ✅ | 数字对账 |
| 3️⃣ 算占比 | 90% 国内 + 10% 国际 | 业务结构 |
| 4️⃣ 年化 | 89.1 × 52 = 4,632 亿度 | 对应"准三峡"级集团 |

### 案例 2：同比增长段

> "国内上网电量 80.3 亿度，同比 +3.2%，主要原因是水电、新能源"

**怎么读**：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1️⃣ 还原基期 | 80.3 ÷ 1.032 = 77.81 | 去年是 77.81 亿度 |
| 2️⃣ 算增量 | 80.3 − 77.81 = 2.49 | 同比多发 2.49 亿度 |
| 3️⃣ 找原因 | "水电、新能源" | **没说火电** = 火电没涨 |
| 4️⃣ 推潜台词 | 火电没提 = 持平或下降 | "绿电驱动"故事 |

### 案例 3：水电调度段

> "大水电完成率 31.8%，时间进度 38.9%"

**怎么读**：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1️⃣ 第一反应 | 落后 7.1 pp？ | ❌ 错了 |
| 2️⃣ 反转视角 | 1-5 月来水少 = 自然滞后 | ✅ 正确 |
| 3️⃣ 深度解读 | 蓄水等汛期 | 6-9 月会追回 |
| 4️⃣ 真实信号 | 上周 103.3% 超额 | 调度做得好 |

### 案例 4：来水反差段

> "三峡偏丰 121.6%，乌东德偏枯 13.9%"

**怎么读**：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1️⃣ 还原数字 | +121.6% = 2.2 倍 | 翻倍 |
| 2️⃣ 想地理 | 乌东德在金沙江，三峡在长江中游 | 不同流域 |
| 3️⃣ 找原因 | 雨带北抬到长江中游 | 5 月底 6 月初规律 |
| 4️⃣ 推后续 | 7-8 月雨带西移 | 乌东德会"翻盘" |

### 案例 5：价格变化段

> "度电均价 0.311 元，同比 −0.9 分"

**怎么读**：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1️⃣ 找"价" | 0.311 元/度 | 偏低（说明水电占比高） |
| 2️⃣ 找变化 | 同比 −0.9 分 | 价格小幅下跌 |
| 3️⃣ 量价分解 | 电量 +3.3%，度电 −0.9 分 | "以量补价" |
| 4️⃣ 算收入 | 0.311 × 80.3 = 24.97 亿 | ≈ 24.9 亿 ✅ |

### 案例 6：品类分析段

> "水电 −0.1 / 新能源 −1.3 / 火电 −3.6 分"

**怎么读**：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1️⃣ 数字排序 | 火电跌最多 (-3.6) | 火电最受伤 |
| 2️⃣ 找原因 | 平价 / 市场化 / 中长期 | **行业大势** |
| 3️⃣ 算总影响 | -0.2 + -0.3 + -0.4 = -0.9 | **数字勾稽** |
| 4️⃣ 推结论 | "以量补价"接近极限 | 需新增长极 |

### 案例 7：地区策略段

> "湖北 95% 锁价 / 山东 0% 持仓 / 陕西 105% 卡线"

**怎么读**：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1️⃣ 对比策略 | 三个省三种相反策略 | "一省一策" |
| 2️⃣ 找原因 | 现货价不同 / 监管规则不同 | 本地化运营 |
| 3️⃣ 推能力 | 集团具备**省级精细化管理** | 能力证明 |
| 4️⃣ 算风险 | 反向情景下会亏损 | 风险地图 |

### 案例 8：火电欠发段

> "现货价跌 31.71%，火电度电反而涨 3.4 分"

**怎么读**：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1️⃣ 反直觉 | 现货跌 → 火电应该跌 | ❌ 表面矛盾 |
| 2️⃣ 找机制 | 欠发套利 + 容量电费对冲 | ✅ 真正原因 |
| 3️⃣ 算数学 | 少发 → 度电容量电费↑ | 数学原理 |
| 4️⃣ 推本质 | 火电变"电力交易商" | 战略升级 |

## 第六部分：常见误区（必避坑）

### 误区 1：进度快 = 业绩好 ❌

> **场景**：水电"完成率 31.8% < 时间进度 38.9%"
> **错误解读**：落后了，工作没做好
> **正确解读**：水电**蓄水策略**——汛期前故意少发，腾库容迎洪水

### 误区 2：度电降 = 业绩降 ❌

> **场景**：集团度电下降 0.9 分
> **错误解读**：电价跌了，业绩变差
> **正确解读**：可能是**结构调整**（火电占比↓ = 度电被"拉低"）

### 误区 3：来水多 = 发得多 ❌

> **场景**：上周来水偏丰 94%
> **错误解读**：来水多 → 应该多发
> **正确解读**：取决于**调度策略**——来水多可以**多蓄少发**等汛期

### 误区 4：度高 = 业绩好 ❌

> **场景**：火电度电 0.421 元，比光伏 0.340 元高
> **错误解读**：火电更赚钱
> **正确解读**：火电度高但**量少**，且**收入仅 1.3 亿**；水电度低但**量大**，**收入 16.7 亿**

### 误区 5：同比好看 = 业绩好 ❌

> **场景**：同比偏丰 100.66%
> **错误解读**：业绩翻倍，太好了
> **正确解读**：可能是**基期效应**——去年是异常枯水年，基数极低

### 误区 6：新能源度电高 = 好 ❌

> **场景**：新能源度电 0.381 元，比水电 0.283 高
> **错误解读**：新能源比水电赚钱
> **正确解读**：新能源**补贴退坡**持续，**度电长期下行**；水电**稳定**

## 第八部分：国际上网电价入门（跨国生意的三个特殊变量）

> 上一章我们把"国内上网电价"讲透了——几分 × 几亿 = 几亿。
> 这一章走出国门，国际电价**多了一个看不见的"汇率幽灵"**，多了一份"合同账本"，多了一盘"区域分化"的棋。
> 读国际段，请先把国内的"金下/清江/湖北"放一放，记住**汇率、卡洛特、各国真本事**三件新武器。

---

### 1. 心智模型：跨国小商品代购店

**场景**：你是一个"全球小商品代购店"的老板。

- 你在**巴西、欧洲、亚非**都有进货渠道
- 客户用**当地货币**跟你结账
- 但老板看总账时，要**全部折算成人民币**才能比高低

**这个月算总账时**：

```
国际总营收 = Σ（各国度电 × 各国家电量） × 各国汇率
```

> 💡 **核心洞察**：
> 国际电价比国内**多两层"看不见的折算"**——
> 1. **各国家度电**（不同国家单价不同）
> 2. **汇率**（当地币种 → 人民币）
> 
> 这两层**任何一个变化，都会影响"人民币口径"的总收入**。

---

### 2. 国际业务的"三个特殊变量"（国内没有）

| 变量 | 国内有没有 | 国际特有影响 | 类比 |
|------|----------|------------|------|
| **汇率变动** | ❌ | 巴西雷亚尔升值 7.6%，同样电量折回人民币"贵了" | 进货的币种涨价了 |
| **合同结构** | ⚠️ 弱 | 卡洛特容量电价——签了长期合同的"VIP 客户" | 签了固定工资的老员工 |
| **区域分化** | ❌ | 巴西/欧洲/亚非，各国独立运营，差别巨大 | 各地分店卖不同商品 |

> 🎯 **小白记住**：看到国际段，**先看这三件事**，再看数。

---

### 3. 国际电价的"4 种价格机制"

| 模式 | 含义 | 典型国家 | 类比 |
|------|------|---------|------|
| **FiT（Feed-in Tariff）** | 国家给固定收购价 | 巴基斯坦、缅甸早期项目 | 国营商店统一定价 |
| **PPA（Power Purchase Agreement）** | 长期合同价 | 大部分国际项目主流 | 签了 5-10 年的大客户 |
| **市场化电价** | 跟当地批发市场走 | 西班牙、巴西 | 集市上随行就市 |
| **双轨制** | 一部分保底 + 一部分市场 | 部分发展中国家 | 底薪 + 提成 |

> 🧠 **小白记住一句话**：
> **国际电价没有"全国统一价"**，每个项目都是**单独谈出来**的。
> 同样的"度电 0.32 元"，在巴西、欧洲、亚非，**含金量完全不同**。

---

### 4. 国际版"度电"计算公式（比国内多一层）

```
国内：    收入 = 量 × 价
国际：    收入 = Σ（各国家度电 × 各国家电量） × 汇率
                        ↑                ↑
                  国家级别细分       汇率折算
```

> ⚠️ **新手最容易踩的坑**：
> 看到"巴西度电 0.27 元"以为便宜——**错**！这是**雷亚尔**，要**先换算成人民币**再比。

### 5. 实战案例 9：国际电价同比 +3.9 分的故事

> "第21周，集团公司国际上网电价约每千瓦时0.32元，同比提高每千瓦时3.9分..."

#### 5.1 三层归因地图（先看骨架）

```
国际电价 0.32 元/度，同比 +3.9 分
├─ 汇率贡献    +1.0 分  (雷亚尔↑7.6%, 美元↓5.6%, 欧元↓30%)
├─ 卡洛特      +0.2 分  (VIP 客户合同价调整)
└─ 真本事      +2.7 分  ⭐ 主动经营能力
```

**验算**：1.0 + 0.2 + 2.7 = **3.9 分** ✅

#### 5.2 真本事怎么来的（2.7 分拆到品类）

```
水电   +1.5 分  ⭐ 主力
├─ 巴西水电：电量减 + 电价涨 → +1.6 分
└─ 秘鲁水电：电价略降 + 高价占比降 → -0.1 分

风电   +1.2 分  ⭐ 第二引擎
├─ 欧洲风电：电量增 + 电价小涨 → +0.4 分
└─ 亚非风电：高价电量增 + 电价不变 → +0.8 分

光伏   ≈ 0
└─ 巴西新投产 Arinos + 欧洲 + 亚非/拉美 → 几乎抵消
```

**验算**：1.5 + 1.2 + 0 ≈ **2.7 分** ✅

#### 5.3 数字翻译成"钱"

国际电量约 **8.8 亿度**，同比 +3.9 分 → **多收约 3,432 万元**：

| 贡献来源 | 影响分 | 折算金额 |
|---------|-------|---------|
| 汇率帮忙 | +1.0 分 | 约 880 万 |
| 卡洛特合同 | +0.2 分 | 约 180 万 |
| **真本事** | **+2.7 分** | **约 2,400 万** ⭐ |

> 💡 这 2,400 万才是**真"内生增长"**——是不靠汇率、不靠老天爷的**实打实能力**。

### 6. 实战案例 10：国际电价环比 +1.3 分的故事

> "环比提高 1.3 分，主要外币汇率（巴西雷亚尔环比贬值 0.5%、欧元贬值 0.5%、美元贬值 0.1%）..."

#### 6.1 三层归因

```
国际电价 0.32 元/度，环比 +1.3 分
├─ 汇率拖累    -0.1 分  (三种外币全贬值)
├─ 卡洛特      -0.02 分
└─ 真本事      +1.4 分  ⭐
```

**验算**：-0.1 + (-0.02) + 1.4 ≈ **1.3 分** ✅

#### 6.2 真本事 vs 同比（单引擎 vs 多引擎）

```
同比真本事  +2.7 分  (水电+1.5, 风电+1.2, 光伏≈0)  → 多引擎驱动
环比真本事  +1.4 分  (风电+1.8, 水电-0.1, 光伏-0.3) → 风电独大
```

> 🚨 **关键观察**：
> - 同比：水电+风电**双轮驱动**
> - 环比：水电**转负**、光伏**转负**，**只剩风电一个引擎**
> - 这就是**动能减弱**的早期信号

#### 6.3 数字翻译成"钱"

环比多收约 **1,144 万元**：
- 汇率少赚：约 88 万
- 卡洛特少赚：约 18 万
- **真本事多赚：约 1,232 万** ⭐

---

### 7. 核心方法论：同比 vs 环比对比框架

> 🆚 **真正值钱的是"两段话合在一起读"**——孤立看一段，故事讲不完整。

#### 7.1 总账对比

| 指标 | 同比 | 环比 | 解读 |
|------|------|------|------|
| 总变化 | +3.9 分 | +1.3 分 | 长期涨幅 > 短期涨幅 |
| 汇率贡献 | +1.0（**帮**）| -0.1（**拖**）| **方向反转** |
| 卡洛特 | +0.2（帮）| -0.02（拖）| 一次性事件消退 |
| **真本事** | **+2.7** | **+1.4** | 内生增长**放缓** |

#### 7.2 品类结构对比

| 品类 | 同比 | 环比 | 解读 |
|------|------|------|------|
| **水电** | +1.5（巴西主力）| -0.1（巴西转负）| ⚠️ **动能反转** |
| **风电** | +1.2（欧+亚非并进）| +1.8（欧独大）| 🚀 **加速 + 更集中** |
| **光伏** | ≈0 | -0.3 | 📉 **开始拖累** |

#### 7.3 三大核心判断

1. **能力维度**：同比 +2.7 分真本事 → **长期能力在积累**
2. **动能维度**：环比 +1.4 分真本事（且结构变差）→ **短期动能在减弱**
3. **结构维度**：从"多点开花"变成"单引擎" → **风险在集中**

---

### 8. 国际电价专属误区（小白必避）

#### 误区 7：汇率涨 = 业绩涨 ❌

> **场景**：巴西雷亚尔升值 7.6%
> **错误解读**：业绩好，国际收入涨了
> **正确解读**：**纸面富贵**——雷亚尔一旦贬值，会反噬同样幅度。
> 同期美元/欧元贬值，**三币种对冲后净影响才 +1 分**。

#### 误区 8：当地涨价 = 集团业绩涨 ❌

> **场景**：西班牙电费上调
> **错误解读**：集团国际收入会涨
> **正确解读**：要看**折回人民币**后是多少——**欧元贬值 30% 足够吃掉所有涨价**。

#### 误区 9：环比好看 = 动能强劲 ❌

> **场景**：环比 +1.4 分
> **错误解读**：动能强劲
> **正确解读**：要看**同比是否还在涨**——同比环比双线才能判断。

#### 误区 10：单引擎 = 危险 ❌（新手看不出来）

> **场景**：环比真本事 +1.4 分全靠风电
> **错误解读**：风电涨了，整体挺好
> **正确解读**：单引擎 = 风险集中。**水电、光伏同时转负**才是真正的预警信号。

### 1. 实战案例 11：水电市场化 — 装修师傅的"长约 + 散单"

> "水电项目：长江干流梯级电站...平均交易电价约为每千瓦时0.304元，同比提高约每千瓦时1.3分...环比降低约每千瓦时0.35分...（南方区域市场收益提高大水电市场化电量度电收益约每千瓦时0.37分，上上周提高约每千瓦时0.75分）..."

#### 1.1 心智模型：装修师傅的"基本盘 + 散单"

**场景**：你是一个装修工程队的老板。

- **基本盘**：和开发商签了**长期装修合同**（稳定主业，单价一般）→ **中长期交易**
- **散单**：周末有业主急装，**高价找你加班**（单价翻倍，但活不稳定）→ **现货市场**
- **本月收入** = 长期合同价 × 长期工时 + 现货高价 × 现货工时

**关键点**：
- 长期合同 = "**养家**"（占比 90%+，稳定）
- 现货 = "**赚花**"（占比 5-10%，高弹性）

#### 1.2 核心术语解码

| 术语 | 含义 | 类比 |
|------|------|------|
| **中长期交易** | 锁定价格 1-3 年 | 长期装修合同 |
| **现货市场** | 实时价格 | 周末高价加班 |
| **D-2** | 提前 2 天的中长期电量 | "昨天的预约" |
| **日前市场** | 提前 1 天的现货 | "今天的临时加单" |
| **国网/南网** | 电力交易的两家"大客户" | 装修业务的两大甲方 |
| **跨省跨区** | 电从 A 省卖到 B 省 | 跨城接活 |
| **较非现货环境增收** | 如果没有现货会少赚多少 | 散单净赚 |

#### 1.3 数字翻译成"钱"（三层结构）

**第 1 层：均价 + 同比/环比**

| 指标 | 数值 | 折算金额（按 9.7 亿度估）|
|------|------|--------------------------|
| 长江干流梯级均价 | 0.304 元/度 | — |
| 同比 | +1.3 分 | 多收 **约 1,261 万元** |
| 环比 | -0.35 分 | 少收 **约 340 万元** |

**第 2 层：本周 vs 上上周"现货贡献"**

| 指标 | 本周 | 上上周 | 变化 |
|------|------|--------|------|
| 现货度电收益 | +0.37 分 | +0.75 分 | **-0.38 分（-51%）** |
| 现货增收 | **534 万元** | **1,120 万元** | **-586 万元（-52%）** |

> 🚨 **关键观察**：现货增收"腰斩"——不是能力问题，是**市场行情**。

**第 3 层：本周具体怎么赚的（按电站拆）**

| 电站 | 成交电量 | 现货价 | 较中长期高 | 增收贡献 |
|------|---------|--------|----------|---------|
| **溪洛渡（溪右）** ⭐ | 6.5 亿度 | 0.312 元 | +0.7 分 | 主力 |
| **乌东德** | 3.2 亿度 | 0.277 元 | +0.2 分 | 辅助 |
| **合计** | 9.7 亿度 | 0.30 元 | +0.6 分 | 534 万 |

#### 1.4 价值所在

1. **透明度**：把抽象的"市场化"翻译成 534 万元
2. **双轮驱动**：长期 + 现货的清晰画像
3. **行情信号**：现货 -52% 是周级别的"高频信号"
4. **决策依据**：是否扩大现货参与？哪个电站更值得参与？
5. **战略验证**：水电从"计划电"走向"市场电"的转型

```

  ┌─【主业】中长期交易 ─────────────────────┐

### 3. 实战案例 13：火电市场化 — 夜班司机的"少发多赚"（案例 8 完整版）

> "火电项目目前仅燃煤机组参与市场交易...平均交易电价为每千瓦时0.402元，同比下降每千瓦时2.8分...环比提高每千瓦时4.6分...上周鄂州#2、#3、#6，宜城#2在运..."

> 🎯 **与第五部分"案例 8"的关系**：案例 8 讲了"现货跌 31.71% → 火电度电涨 3.4 分"的反直觉机制。本案例 13 是**完整版**——把同比、环比、4 台机组、板块对比全部讲透。

#### 3.1 心智模型：夜班出租车司机的"补贴 + 单价"

**场景**：你是夜班出租车司机。

- **白天**：单多、价低（"中长期"）→ 跑 8 小时赚 300 元
- **深夜**：单少、价高（"现货"）→ 跑 5 单赚 200 元
- **这周情况**：
  - **上周**（"上上周"）：深夜单价 0.25 元/公里
  - **本周**：突然大暴雨 → 深夜没人出门 → 单价跌到 0.17 元/公里（**-31.71%**）
- **你的反应**：**不跑了**（"欠发"）→ 回家睡觉
- **但是**：出租车公司给你**"出车补贴"**（"容量电费"）—— 不论跑不跑，每天 500 元保底
- **算总账**：
  - 跑了 5 单 × 10 公里 = 50 公里
  - 流水：50 × 0.17 = 8.5 元
  - + 容量电费 500 元
  - **度电分摊**：508.5 ÷ 50 = 10.17 元/公里（**比平时还高！**）

> 🧠 **小白记住**：
> **当外部条件恶劣时，聪明的火电选择"少发"——但因为有"容量电费"保底，结果反而"少发多赚"**。

#### 3.2 核心术语解码

| 术语 | 含义 | 类比 |
|------|------|------|
| **仅燃煤参与** | 火电里只有燃煤进市场 | 出租车里的"普通车型" |
| **欠发套利** | 主动少发 + 容量电费对冲 | 司机"不出车拿补贴" |
| **容量电费** | 不论发不发都有的保底补贴 | 出租车的"出车补贴" |
| **调节电源** | 按需启停，灵活调整 | 司机"按单数决定跑不跑" |
| **战略性退场** | 4 台机组 vs 整体规模 | 出租车公司"减车" |
| **同比对冲** | 中长期下行 + 容量电费提高 | 收入减少 + 补贴增加 |

#### 3.3 数字翻译成"钱"（三层结构）

**第 1 层：均价 + 同比/环比**

| 指标 | 数值 | 折算金额（按火电 3.1 亿度估）|
|------|------|--------------------------|
| 均价 | 0.402 元/度 | — |
| 同比 | -2.8 分 | 少收约 **868 万元** ⚠️ |
| 环比 | +4.6 分 | 多收约 **1,426 万元** ✅ |

**第 2 层：同比下行的"两层对冲"**

| 因素 | 方向 | 影响 |
|------|------|------|
| 中长期合同 -3 分 | 📉 下行 | 同比下行主力 |
| 现货电价 -X 分 | 📉 下行 | 同比下行辅助 |
| **容量电费提高** | 📈 **上行** | **抵消一部分** |
| **净结果** | -2.8 分 | 下行被对冲 |

> 💡 **数学原理**：
> `度电容量电费 = 容量费总额 / 实际电量`
> 实际电量 ↓ → 分母 ↓ → 度电容量电费 ↑

**第 3 层：环比上行的"反直觉"逻辑**

| 指标 | 本周 | 上周 | 变化 |
|------|------|------|------|
| 现货市场均价 | 0.1710 元 | 0.2503 元 | **-31.71%** ⚠️ |
| 现货价变化 | -7.93 分 | — | 暴跌 |
| **火电度电** | **+4.6 分** | — | **反而涨了** ⭐ |

**验算**：
- (0.2503 - 0.1710) / 0.2503 = 0.3188 = **31.71%** ✅
- 现货价跌 31.71% → 度电涨 4.6 分 = **"少发多赚"经典案例**

#### 3.4 4 台机组的战略意义

> 🚨 **关键观察**：
> - 4 台 = 火电在**战略性退场**
> - 但保留的 4 台 = **保留"调节能力"**（新型电力系统下不可或缺）
> - **不是"消灭火电"，是"重塑火电"**

#### 3.5 价值所在

1. **机制具体化**：欠发套利从理论变成 4.6 分的真实数据
2. **对冲思维**：-3 分中长期 + 容量电费 = -2.8 分
3. **新角色揭示**：从"基荷主力"到"调节电源"
4. **量化系统影响**：负荷 +11 万、风电 +24 万、光伏 -326 万
5. **反向情景**：本周 +4.6 的反向是新能源的 +1.3（零和博弈）

  │  本周卖 2,100 吨 → 17.9 万元         │
  │  2026 累计卖 43.4 万吨 → 363 万元    │
  │  库存 506 万吨 → 约 4,300 万元       │
  └──────────────────────────────────────┘

  💰 合计"环境资产"价值 ≈ 1.07 亿元 ⭐
  
  📌 业务定位：
     传统业务 = 发电 + 售电 + 投资
     第四类业务 = 环境资产（绿证 + CCER）
     毛利率接近 100%（"轻资产"）
```

## 附录 A：常见问答

### Q1：为什么这周水电涨、火电跌？

**A**：火电在"双碳"下面临战略性退场，水电是"绿电主力"获得更多资源。

### Q2：为什么火电度电高、收入却少？

**A**：度电高 ≠ 收入多。火电**度电 0.421**但**量仅 3.1 亿度**，总收入 1.3 亿；水电**度电 0.283**但**量 59 亿度**，总收入 16.7 亿。

### Q3：抽水蓄能是干嘛的？

**A**：储能的一种。**谷时抽水**（耗电便宜）→ **峰时发电**（卖电贵），**赚价差**。

### Q4：为什么周报里"金下"出现这么多次？

**A**：金下梯级是集团**核心资产**（乌东德+白鹤滩+溪洛渡+向家坝），装机占集团一半以上，**来水情况直接决定业绩**。

### Q5：为什么"分"这个单位这么重要？

**A**：在能源行业，"几分钱" × "亿度" = "几十亿"。周报里所有小数点后两位的数字都关乎**上亿**的利润博弈。

### Q6：如何识别周报的"潜台词"？

**A**：看"**没写出来的字**"——
- 没提火电 = 持平或下降
- "主要原因是水电" = 结构在变绿
- 同比 +0.3% ≈ 几乎不增长
- 数字详细 = 集团重点关注
